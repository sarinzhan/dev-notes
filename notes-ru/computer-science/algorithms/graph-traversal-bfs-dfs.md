## Кратко
Поиск в ширину (BFS) исследует граф уровень за уровнем с помощью очереди и даёт **кратчайший путь по числу рёбер** в невзвешенных графах. Поиск в глубину (DFS) уходит как можно глубже с помощью стека (или рекурсии) и служит инструментом для **связности, обнаружения циклов, топологического порядка и перечисления путей**. Оба работают за O(V + E) со списком смежности, и обоим нужно множество `visited`, иначе циклы зацикливаются навсегда. Компромиссы представления графа описаны в [[graphs-representation]]; эта заметка — про два обхода и задачи, построенные на них.

## Основное

### Напоминание о представлении
- Список смежности `List<List<Integer>>` или `Map<Node, List<Node>>`: память O(V + E), дешёвый перебор соседей; вариант по умолчанию.
- Матрица смежности `boolean[V][V]`: память O(V²), проверка ребра за O(1); только для плотных или крошечных графов.
- Неявные графы: сетка, где соседи — четыре окружающие клетки, пространство состояний (word ladder, позиции головоломки), дерево зависимостей сборки ([[maven]]). Их никогда не материализуют, соседей вычисляют на лету.

### BFS
- Очередь вершин фронта; помечай посещённой **при добавлении в очередь**, а не при извлечении, иначе вершины будут добавляться много раз.
- Учёт расстояния: либо храни пары `(node, dist)`, либо обрабатывай очередь по уровням (`int size = q.size(); for (size) {...}`).
- BFS из нескольких источников: сначала добавь все источники с расстоянием 0 (гниющие апельсины, ближайшая больница). Стоимость та же, что у одного источника.
- 0-1 BFS: если веса рёбер только 0 и 1, используй дек и добавляй 0-рёбра в начало; это заменяет Дейкстру ([[shortest-paths-dijkstra]]).
- Двунаправленный BFS вдвое уменьшает показатель степени для огромных неявных графов (word ladder).

### DFS
- Рекурсивную версию писать короче всего; итеративную с `ArrayDeque` — для графов глубже нескольких тысяч вершин ([[recursion-and-backtracking]]).
- Трёхцветная пометка для **обнаружения цикла в ориентированном графе**: белый = не посещён, серый = на текущем пути, чёрный = обработан. Ребро в серую вершину — обратное ребро, то есть цикл. Для неориентированных графов цикл означает посещённый сосед, который не является родителем.
- Времена завершения (post-order) в обратном порядке дают топологический порядок ([[topological-sort-and-union-find]]).
- Компоненты связности: запускай DFS/BFS из каждой непосещённой вершины, считай запуски. Union-find — альтернатива, когда рёбра поступают постепенно.
- Заливка сетки (flood fill, «количество островов») — это DFS по неявному графу; рекурсия на сетке 1000×1000 переполняет стек, используй итеративный вариант.

### Выбор
| Нужно | Использовать |
|---|---|
| кратчайший путь, невзвешенный граф | BFS |
| кратчайший путь, неотрицательные веса | Дейкстра ([[shortest-paths-dijkstra]]) |
| любой путь, достижимость, компоненты | DFS или BFS |
| обнаружение циклов, топологический порядок | DFS (или BFS по Кану для топосортировки) |
| все пути / перечисление с ограничениями | DFS с возвратом (backtracking) |
| ответы с учётом уровней (минимум ходов, ближайший X) | BFS |
| ограниченная память на широких графах | DFS (O(глубины)), а не BFS (O(ширины)) |

### Сложность
| Обход | Время | Память |
|---|---|---|
| BFS, список смежности | O(V + E) | O(V) очередь + visited |
| DFS, список смежности | O(V + E) | O(V) visited + O(глубины) стек |
| любой, матрица смежности | O(V²) | O(V) |

### Где встречается в работе
- Разрешение зависимостей и «какие сервисы затронуты, если X упадёт» в графе сервисов ([[api-gateway-and-service-discovery]]).
- Проверка DAG workflow перед планированием ([[temporal-concepts]], [[background-jobs-and-schedulers]]).
- Сборка мусора помечает достижимые объекты обходом от корней GC ([[garbage-collection]]).
- Краулеры, деревья наследования прав, оргструктуры, «друзья друзей» в [[design-news-feed]].

## Пример
```java
// Наименьшее число переходов между двумя сервисами в графе вызовов (невзвешенном), BFS.
// Возвращает -1, если недостижимо. Граф: сервис -> список сервисов, которые он вызывает.
static int hops(Map<String, List<String>> calls, String from, String to) {
    if (from.equals(to)) return 0;
    Deque<String> queue = new ArrayDeque<>();
    Map<String, Integer> dist = new HashMap<>();      // заодно служит множеством visited
    queue.add(from);
    dist.put(from, 0);
    while (!queue.isEmpty()) {
        String cur = queue.poll();
        for (String next : calls.getOrDefault(cur, List.of())) {
            if (dist.containsKey(next)) continue;     // помечаем при добавлении, а не при извлечении
            dist.put(next, dist.get(cur) + 1);
            if (next.equals(to)) return dist.get(next);
            queue.add(next);
        }
    }
    return -1;
}

// Обнаружение цикла в ориентированном графе тремя цветами, DFS. 0 = белый, 1 = серый (в процессе), 2 = чёрный.
static boolean hasCycle(Map<String, List<String>> g) {
    Map<String, Integer> color = new HashMap<>();
    for (String v : g.keySet())
        if (color.getOrDefault(v, 0) == 0 && dfs(g, v, color)) return true;
    return false;
}
private static boolean dfs(Map<String, List<String>> g, String v, Map<String, Integer> color) {
    color.put(v, 1);
    for (String w : g.getOrDefault(v, List.of())) {
        int c = color.getOrDefault(w, 0);
        if (c == 1 || (c == 0 && dfs(g, w, color))) return true;   // серый сосед = обратное ребро
    }
    color.put(v, 2);
    return false;
}
```

## Подводные камни
- Пометка посещённой при извлечении: одна и та же вершина добавляется в очередь по разу на каждое входящее ребро, и на плотных графах очередь раздувается до O(E).
- Использование расстояния BFS во взвешенном графе; первое достижение вершины — не самое дешёвое.
- Рекурсивный DFS на больших входных данных: `StackOverflowError` где-то на глубине 10–20 тыс. со стеками потоков по умолчанию ([[jvm-memory-areas]]).
- Обнаружение цикла в ориентированном графе только с булевым `visited`: посещённая чёрная вершина — это не цикл; нужно состояние «на текущем пути».
- Изменение `List` соседей во время его обхода в DFS бросает `ConcurrentModificationException` ([[iterators-and-fail-fast]]).
- Связанные заметки: [[graphs-representation]], [[topological-sort-and-union-find]], [[trees-and-bst]] (обходы деревьев — это DFS/BFS без множества visited), [[interview-problem-patterns]].
