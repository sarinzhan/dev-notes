## Кратко
Классы связаны друг с другом шестью способами: зависимость (использует разово), ассоциация (хранит ссылку), агрегация (has-a, части живут сами по себе), композиция (has-a, владелец управляет временем жизни частей), наследование (is-a) и реализация интерфейса. Сила связи растёт от зависимости к композиции; выбор самого слабого отношения, которого достаточно, сохраняет слабую связанность кода.

## Основное
| Отношение | Смысл | Стрелка UML | Как выглядит в Java |
|---|---|---|---|
| Зависимость (dependency) | A временно использует B: параметр, локальная переменная, тип возврата | пунктирная стрелка | `void pay(PaymentGateway gw)` |
| Ассоциация (association) | A хранит ссылку на B и вызывает его | сплошная линия | `private final Clock clock;` |
| Агрегация (aggregation) | has-a, слабая: часть может существовать без целого и может быть общей | пустой ромб у целого | `Library` хранит `List<Book>`; книга может перейти в другую библиотеку |
| Композиция (composition) | has-a, сильная: целое создаёт и уничтожает свои части, части не разделяются | закрашенный ромб у целого | `Book` хранит `List<Page>`; страницу нельзя вырвать и вставить в другую книгу |
| Наследование (inheritance) | is-a: подкласс расширяет суперкласс | сплошная стрелка, пустой наконечник | `class Admin extends User` |
| Реализация (realization) | класс реализует интерфейс | пунктирная стрелка, пустой наконечник | `class JdbcUserRepo implements UserRepository` |

- Агрегация и композиция — частные случаи ассоциации. Практическая проверка: если удаление владельца обязано удалить части — это композиция; если части выживают — агрегация.
- Ассоциация бывает однонаправленной или двунаправленной и имеет кратность (1, 0..1, *). В JPA это напрямую отображается на `@OneToMany`, `@ManyToOne` и т. д. ([[jpa-entities-and-relationships]]).

### Композиция вместо наследования
- Наследование открывает подклассу все protected-детали родителя и фиксируется во время компиляции; композиция позволяет подменить соавтора (через интерфейс) во время выполнения и протестировать его с заглушкой.
- Наследование стоит использовать, только когда подкласс действительно может заменить родителя (принцип Лисков, см. [[solid]]). «`Stack` расширяет `Vector`» в JDK — классическое нарушение: стек открывает `insertElementAt`.
- Внедрение зависимостей (dependency injection, [[spring-ioc-and-di]]) — это композиция, выполняемая контейнером.

### Что такое класс на самом деле
- Класс — это классификация: именованное множество объектов с общей структурой и поведением. Классифицировать можно по уровню абстракции (`Account` абстрагируется от «сберегательного» и «текущего»), что и выражают иерархии наследования.
- Класс с единственным методом и без состояния — это просто замаскированная функция; класс с состоянием и без поведения — это record. Умение распознать оба случая избавляет от лишних церемоний.

## Пример
```java
// Композиция: Order владеет своими строками; агрегация: Order ссылается на Customer, который существует сам по себе
public final class Order {
    private final Customer customer;              // агрегация: общий, живёт независимо
    private final List<OrderLine> lines = new ArrayList<>(); // композиция: создаётся и уничтожается вместе с заказом
    private final PriceCalculator calculator;     // ассоциация через интерфейс, внедряется

    public Order(Customer customer, PriceCalculator calculator) {
        this.customer = customer;
        this.calculator = calculator;
    }

    public void addLine(Product product, int qty) {   // зависимость от Product (только параметр)
        lines.add(new OrderLine(product.sku(), product.priceMinor(), qty));
    }

    public long totalMinor() { return calculator.total(lines); }
}
```

## Подводные камни
- Композиция, которая раздаёт ссылки на свои части (`getLines()` возвращает живой список), незаметно превратилась в агрегацию; возвращай неизменяемое представление ([[immutable-objects]]).
- Двунаправленные ассоциации удваивают сопровождение: обе стороны нужно обновлять вместе. В JPA, если об этом забыть, появляются строки-сироты или внешние ключи со значением `null`.
- Наследование только ради переиспользования кода («`Report extends ReportHelper`») ведёт к хрупким базовым классам; вынеси помощника и используй композицию.
- Связанные заметки: [[oop-principles]], [[structural-patterns]] (Decorator, Adapter и Composite построены на композиции).
